[README.md](https://github.com/user-attachments/files/33205500/README.md)# Curve Digitizer v1

将论文图表中的曲线转换为可分析的坐标数据。项目提供 MATLAB 图形界面和批处理入口，支持坐标标定、曲线提取、原图叠加核对，以及 CSV、Excel、MAT 导出。

适合从已有图像中恢复曲线趋势、整理参考数据和辅助复现。数字化结果受图像分辨率、标定和遮挡影响，使用前请检查叠加图。

## 运行环境

- MATLAB R2023b 或更新版本，建议使用桌面环境运行图形界面。
- Image Processing Toolbox：曲线提取、自检和核对脚本使用图像处理函数。
- 较早版本的 MATLAB 可能需要 Statistics and Machine Learning Toolbox 提供 `prctile`；本项目不保证旧版本兼容性。

图片提取和数据导出无需安装 Python。当前包的 PDF 矢量抽取入口缺少 `extract_pdf_figure.m`，暂不可用；仅安装 PyMuPDF 不能补齐该功能。请先将 PDF 中的图保存为图片，再通过“载入图片”处理。

## 快速开始

解压后，在 MATLAB 中将“当前文件夹”切换到包含 `app.m` 的项目目录，然后运行：

```matlab
app
```

`app` 仅打开图形界面，不自动执行自检或批量提取。也可以直接运行 `digitizer_app`。

首次使用建议单独执行：

```matlab
selftest
```

自检会检查依赖、试跑七张示例图并检查已知图片识别。若提示缺失函数或曲线数量不符，请先处理对应问题。

## 通过界面处理图片

1. **载入图片。** 选择完整的单幅图像。多面板拼图请先在外部裁成单幅，当前界面不提供面板裁剪按钮。为避免错误套用示例标定，不要把自己的图片命名为 `fig2E` 或 `fig3A`～`fig3F`。
2. **确认坐标轴框。** 核对绘图区边界，避免将零线、网格线或图例边框当作坐标轴。
3. **标定。** 按提示填写坐标范围，并核对这些数值对应的刻度位置。程序可识别随包示例并使用预设标定；自己的图片仍需检查标定。
4. **自动分离曲线。** 输入期望曲线条数，再选择全部提取、指定序号或手动点选。点选时优先选择曲线清晰、远离交叉和标记点的位置，结束后点击“完成选择”。
5. **核对结果。** 点击“重叠验证”，青色细线为提取轨迹。通过“显示提取曲线”开关对比原图，放大检查交叉、尖峰和遮挡处。“数据曲线”打开独立坐标图。
6. **导出数据。** 填写曲线名称、轴名称和单位，选择保存位置。通常生成 CSV、Excel、MAT 和来源说明文件；Excel 写出失败时请查看警告和实际生成的文件。

界面保留了可选的平滑拟合和大点影响处理。平滑可能改变真实起伏，建议先保留原始细节，并在使用后重新检查叠加结果。

## 批量提取示例

批处理使用 `data/` 中的七张示例图及 `fig_specs_v2.m` 中的预设标定，不会扫描任意新图片。

```matlab
% 提取全部示例并生成数据与核对图
OUT = run_all;

% 只处理指定示例
OUT = run_all('figures', {'fig3B', 'fig3D'});

% 关闭 Excel 导出，保留 CSV 和 MAT
OUT = run_all('xlsx', false);

% 仅保存 MAT 和核对产物
OUT = run_all('csv', false);
```

默认结果写入 `digitized_final/`，核对图和质量报告写入 `qa/`。重新运行会覆盖同名结果；请先保存需要保留的数据。

`OUT` 为结构体数组，包含 `tag`、`curves` 和 `qc`。例如：

```matlab
plot(OUT(1).curves(1).X, OUT(1).curves(1).Y);
xlabel('X'); ylabel('Y'); grid on;
```

批处理参数由 `extract_opts.m` 管理。当前 `fig3B`、`fig3C`、`fig3D`、`fig3E` 分支不启用 `snake_smooth`，使用针对性的颜色证据校正；缺失片段仍可能通过直线插值或端点延伸补齐。`fig2E`、`fig3A` 保留平滑先验，`fig3F` 使用颜色重吸附。

## 导出文件

### 图形界面

| 文件 | 内容 |
|---|---|
| `<名称>.csv` | 各曲线的 X/Y 成对列，列名根据名称和单位整理 |
| `<名称>.xlsx` | `ALL` 汇总工作表及各曲线工作表 |
| `<名称>.mat` | `curves`、轴标签 `lab`、标定 `cal` 和轴框 `ax` |
| `<名称>_provenance.txt` | 图片路径、导出时间、坐标范围、曲线列表等来源信息 |

### 批处理

| 文件 | 内容 |
|---|---|
| `<tag>.csv` | 宽表：`x1,y1,x2,y2,...`；较短系列用 NaN 补齐 |
| `<tag>_long.csv` | 长表：`series,x,y`，方便筛选、分组和绘图 |
| `<tag>.xlsx` | 各曲线 X/Y 成对列 |
| `<tag>.mat` | 结构体数组 `CR`，包含像素坐标 `px/py`、数据坐标 `X/Y` 等字段 |

界面导出与批处理 MAT 的变量结构不同，读取时请按对应字段操作。例如：

```matlab
D = load(fullfile('digitized_final', 'fig3D.mat'));
plot(D.CR(1).X, D.CR(1).Y);
```

## 结果核对

整理版保留了原包中的示例数据、叠加图和独立重绘图，便于查看输出形式；这些是随包结果，本次整理未重新执行 MATLAB 提取。当前质量指标请在自己的运行环境中重新生成。

```matlab
verify_all
```

该命令依次执行自检、批处理、笔画覆盖分析、失真检查、标定校验、边界测试和分辨率测试，报告写入 `qa/VERIFY_report.txt`。脚本会捕获并记录失败，因此出现“验证结束”不等于全部检查通过，需查看报告中的失败项。

常用核对产物：

| 产物 | 用途 |
|---|---|
| `qa/<tag>_overlay.png` | 原图与品红提取轨迹叠加 |
| `qa/<tag>_render.png` | 用提取数据独立重绘 |
| `qa/<tag>_check.png` | 按偏离笔画中心的程度着色，由 `render_check` 生成 |
| `qa/linegap_<tag>.png` | 标记未覆盖的曲线笔画 |
| `qa/QC_report.txt` | 曲线数量、覆盖率及像素偏差等指标 |

需要进一步检查时，可运行 `check_kinks`、`check_bias2`、`check_flip`、`check_profile` 或 `check_calib`。覆盖率衡量图像笔画被路径认领的程度，不能单独证明坐标准确或曲线身份正确。

## 使用限制与常见问题

- **提示找不到函数：** 确认 MATLAB 当前文件夹为项目根目录，项目已完整解压。缺少 `bwdist`、`bwmorph` 等函数时，检查 Image Processing Toolbox。命令行 `selftest` 是随包主流程自检；界面的环境检查仍包含旧版外部模块检查，可能报告包内未提供的函数。
- **曲线跳线、靠近圆点或漏掉尖峰：** 放大叠加图检查，核对曲线条数和轴框，必要时重新选择清晰的种子点。曲线重叠、同色合并、低分辨率及误差棒会增加提取难度。
- **图像一致但坐标范围不对：** 检查轴框边界与所填刻度的对应关系；本项目批处理采用线性像素到数据坐标映射，不应直接用于对数坐标图。
- **遮挡处看起来连续：** 路径连续可能来自插补或延伸，该位置未必存在可直接观测的数据。应对照原图判断。
- **导出文件内容：** 曲线编号不自动对应实验条件，请人工确认名称和单位。当前界面生成的来源说明含旧版 OCR 和精度描述，不能作为本次提取的精度证明。
- **科研引用：** 请注明数据由图示数字化得到，并保留原图、标定信息和核对结果。项目包未提供许可证及示例图片授权声明，不能据此推定其授权范围。
